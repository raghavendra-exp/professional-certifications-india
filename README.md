## ✨ Key Features

- **Mobile-First & Desktop Optimized**: Responsive layout from 320px smartphones to 4K ultra-wide monitors with sticky sub-navigation, breadcrumbs on every page, and zero horizontal scroll.
- **Bilingual English + Hindi (द्विभाषी)**: Complete language switching across all navigation, metadata, explanations, question stems, options, and statute summaries.
- **PWA-Ready & Offline First**: Includes Web App Manifest, offline local storage persistence for bookmarks, error log tracking, mock scores, and study plans.
- **Copyright-Safe & Data-Driven**: Based strictly on official syllabi, public acts, Gazette notifications, and verified past year questions with rigorous statutory citations.
- **Instant Global Search**: Modal search (`Ctrl+K` / `⌘K`) indexing all certifications, papers, statutes, standards, books, case studies, and career paths in real-time.
- **Dark, Light & System Themes**: High-contrast, accessibility-audited color schemes for long study sessions.

## 🛠 Interactive Labs & Engines

1. **Practice Question Hub**:
   - Filter by certification, level, paper, and topic.
   - Verified PYQs and official sample questions with negative marking calculation.
   - Rich explanations citing statutory sections, accounting standards, and formulas.
   - Bookmark questions and one-click export to Error Notebook.

2. **CBT Mock Examination Simulator**:
   - Timed examination environment mimicking real computer-based testing (CBT).
   - Question palette with status indicators (*Answered*, *Marked for Review*, *Unanswered*).
   - Detailed analytics breakdown with accuracy percentage, domain-wise score, and time spent.

3. **Case Study & Problem Solving Lab**:
   - Multi-disciplinary practical case studies for CA Final, CS Professional, and CISA.
   - Multi-step structured analysis with corporate facts, legal issues, applicable sections, and model solutions.

4. **Interactive Financial & Practical Simulators**:
   - **Indian Tax Regime Simulator (FY 2025–26 / AY 2026–27)**: Real-time side-by-side tax liability comparison between New Tax Regime (Section 115BAC with enhanced standard deduction and slab rebate u/s 87A) and Old Tax Regime (Section 80C, 80D, HRA, 24b).
   - **DuPont Return on Equity (ROE) Calculator**: Interactive 3-step and 5-step decomposition of Return on Equity into Operating Margin, Asset Turnover, Financial Leverage, Tax Burden, and Interest Burden.

5. **High-Yield Statutes & Standards Library**:
   - Authoritative summaries and key exam provisions for:
     - Companies Act, 2013 (Sec 135 CSR, Sec 138 Internal Audit, Sec 139-147 Statutory Audit, Sec 148 Cost Audit, Sec 204 Secretarial Audit).
     - Income Tax Act, 1961 (Sec 115BAC, Sec 44AB Tax Audit, Sec 194C/J/Q TDS, Sec 54 Capital Gains).
     - CGST Act, 2017 & IGST Act, 2017 (Sec 7 Supply, Sec 16 & 17(5) ITC, Reverse Charge).
     - Insolvency and Bankruptcy Code (IBC), 2016 (CIRP Timeline, Section 7/9/10, Section 29A disqualification, Section 53 Waterfall).
     - Ind AS 115 (Revenue from Contracts with Customers — 5 Step Model).
     - Ind AS 116 (Leases — Right-of-Use Asset & Lease Liability).
     - Standards on Auditing (SA 700, 701 Key Audit Matters, SA 240 Fraud).
     - Information Security & Governance (NIST CSF 2.0, COBIT 2019, Basel III Capital Adequacy).

6. **Spaced Repetition Flashcards**:
   - High-yield formula cards, section numbers, accounting standard numbers, and definitions.
   - Leitner system self-assessment (*Hard*, *Good*, *Easy*).

7. **Error Notebook**:
   - Automatically tracks questions missed in practice or mock tests.
   - Add personal reflection notes and mark as resolved once mastered.

8. **"Which Certification Is Right For You?" Decision Wizard**:
   - 4-step recommendation engine matching educational background, career goals, weekly study bandwidth, and budget to the ideal credentials.

9. **Career Progression Explorer**:
   - Interactive role roadmaps for Corporate Auditing, Investment Banking, Information Security, and Corporate Governance with indicative Indian CTC bands (Entry, Mid, Senior, Executive).

10. **Side-by-Side Certification Comparison Matrix**:
    - Compare up to 3 credentials simultaneously on exam duration, passing rate, practical training duration, total fees, and global reciprocity.

11. **12-Week Dynamic Study Planner**:
    - Customized weekly milestone schedules with checkboxes, phase tracking (Foundation, Deep Dive, Revision, Mock Tests), and progress percentage.

12. **Renewal & CPE/CPD Credit Ledger**:
    - Track annual continuing professional education hours, certificate validity dates, and download CPE compliance logs.

## 🌐 Bilingual Architecture (English + Hindi)

Every data entity supports dual-language presentation:
```typescript
export interface Question {
  id: string;
  stem: string;
  hindiStem?: string;
  options: {
    id: string;
    text: string;
    hindiText?: string;
  }[];
  explanation: string;
  hindiExplanation?: string;
  statutoryReference?: string;
}
```
Toggle seamlessly between English and Hindi at any point without losing exam timer progress, active answers, or form states.

## 🚀 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/raghavendra-exp/professional-certifications-india.git
   cd professional-certifications-india
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build production bundle**:
   ```bash
   npm run build
   ```
   The production-ready artifacts will be compiled into the `dist/` directory.

## 📦 GitHub Pages Deployment

The repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically builds and deploys the application to GitHub Pages whenever changes are pushed to the `main` branch.

### Enabling GitHub Pages in Repository Settings:
1. Navigate to **Settings** > **Pages** in your GitHub repository.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Push to `main` branch: GitHub Actions will build and deploy the application automatically.
